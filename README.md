# MNIST Dimensionality Reduction and Classification

## Project Overview
This project investigates the impact of dimensionality reduction techniques on classification performance using the MNIST handwritten digit dataset.

## Methods
- Baseline SVM
- PCA
- LDA
- LLE

## Topics Covered
- Dimensionality Reduction
- Representation Learning
- Feature Engineering
- Manifold Learning
- Classification Evaluation

## Technologies
- Python
- Scikit-learn
- NumPy
- Matplotlib
- Seaborn
- Google Colab
